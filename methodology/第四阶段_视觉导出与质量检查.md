# 第四阶段：视觉导出与质量检查

## 1. 阶段目标

将第三阶段交互式看板转化为可复用、可插入飞书文档的静态视觉材料，并在真实浏览器环境完成最终视觉验收。

## 2. 本阶段产出

- 1 份完整页面预览图
- 5 份独立章节图
- 1 份支持章节导出参数的离线交互式 HTML
- 图片清单与看板使用说明

## 3. 导出方式

交互式看板支持以下章节参数：

- `?section=overview`
- `?section=funnel`
- `?section=profile`
- `?section=channel`
- `?section=strategy`

启用章节参数后，页面只显示指定章节，以保证报告插图不混入其他章节内容。

## 4. 质量检查结果

| 检查项 | 结果 | 说明 |
|---|---|---|
| 章节边界 | 通过 | 五张章节图均仅包含目标章节 |
| 标签完整性 | 通过 | 修正设备转化率顶部数值裁切 |
| 数值一致性 | 通过 | KPI、漏斗与阶段二分析结果一致 |
