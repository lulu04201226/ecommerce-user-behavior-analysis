# 分析审计表

本目录保存可用于复核项目结论的聚合结果：

- `funnel_audit.csv`：五级漏斗到达量、环节分母和转化率。
- `user_type_transition_audit.csv`：新老用户分环节转化率及实际样本基数。
- `channel_standardization_summary.csv`：渠道原始和结构标准化转化率。
- `channel_standardization_cells.csv`：标准化联合分层、权重及小样本检查。
- `visit_depth_analysis.csv`：访问深度分组、样本量和转化率。
- `uplift_scenarios.csv`：核心环节不同绝对提升幅度下的理论机会量。
- `data_quality_summary.json`：数据质量与异常检查摘要。

这些文件均为聚合或审计结果，不包含可识别个人信息。
